# SaaS Churn & Revenue Analytics Platform

## Project Overview

This project analyzes customer churn and revenue performance for CloudMetrics, a B2B SaaS company.

The objective is to identify churn drivers, customer behavior patterns, revenue opportunities, and retention strategies.

---

## Dataset

The project uses four datasets:

- saas_customers.csv
- saas_subscriptions.csv
- saas_usage.csv
- saas_tickets.csv

## Key Findings

- Churn impacts recurring revenue growth.
- Lower product usage is associated with higher churn risk.
- Enterprise customers generate the highest revenue contribution.
- High-risk accounts represent significant revenue exposure.
